01 — Context

The Problem

Two competing sites. One protocol name. The wrong site is winning — on Google, on AI, and in the Chinese market.

rgb.tech → LNP/BP Standards Association / Maxim Orlovsky / v0.12   |   rgb.info → RGB Protocol Association / Bitfinex ecosystem / v0.11.1

FAILURE MODE 01

AI routes developers to the competition

rgb.tech is the default answer on every single platform tested. rgb.info does not appear as a primary destination on any of them. The Association's voice is absent at the exact moment a developer decides which protocol to build on.

FAILURE MODE 02

The fork narrative is winning by default

Grok tells developers verbatim: "RGB v0.11.1 is an unauthorized fork by Bitfinex. Do not use it." The security notice has citations. The Association has published zero response. Silence is losing.

FAILURE MODE 03

rgb.info is described as a dead site

DeepSeek tells users rgb.info is "an archive of older versions, no longer actively maintained." Perplexity: "not in the primary official doc set." These are the answers before anyone visits the site.

FAILURE MODE 04

The Chinese market is lost to a different protocol

RGB++ (Nervos/CKB) has dominated Chinese-language Bitcoin media since 2024. DeepSeek has almost no correct Association content. Asia-Pacific leads global stablecoin flows: $407B inflows. USDT is 61% of Asian crypto transactions. Tether chose RGB — Asia doesn't know yet.

04 — Analysis

Content Gap & Technical SEO

rgb.tech has

  • Detailed whitepaper (blackpaper.rgb.tech)
  • Technical standards (standards.lnp-bp.org)
  • Blog with release posts going back years
  • Multiple wallets and tools listed
  • GitHub org authority (RGB-WG)

rgb.info is missing

  • "RGB v0.11.1 vs v0.12 — why we shipped" page
  • "State of the ecosystem" page (wallets, DEXes, tools)
  • Blog posts ranking for competitive keywords
  • Response to the security notice
  • Developer tutorials with code
  • About/organization page (who is the Association?)
  • Meta descriptions and keyword-rich page titles
  • Updated multimedia hub — speeches, articles, and videos are outdated; recent content (Federico Tenga SLP692, BitMask mainnet coverage, Tether USDT launch) is missing from the site entirely

Technical SEO — Quick Fixes

  • Page title is just "RGB" → should be "RGB Protocol | Bitcoin Smart Contracts on Lightning"
  • No meta description on any page
  • Shallow site depth — few internal pages = few indexable URLs
  • Heavy CSS/JS payload may slow load speed
  • rgb.info and rgb.tech share the same technical SEO weaknesses — rgb.info can leapfrog by fixing these first
